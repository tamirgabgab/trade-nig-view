# UX Profile

Hand-written for ChartLab (U1a, 2026-11-23) from the VectorLab template. All UI/UX skills in this project read
this file before changing layout, copy, or interaction. It will be refined round by round.

## Product

- **What:** a personal, local, dense charting terminal (TradingView-style), used with a mouse and keyboard on Windows.
- **Primary page pattern:** split pane (chart workspace + left tool rail + right widget sidebar + top/bottom bars).
- **Viewports:** desktop first. Supported: 960 px (half a 1920 screen) and up. Below 1100 px the right sidebar floats
  over the chart. Phones (375 px) are out of scope for now.

## Aesthetic reference

- **Standard:** Custom: TradingView-like dark terminal (the user chose to keep its colours, 2026-11-23).
- **Notes:** quiet and professional. The chart is the hero; chrome stays flat and recedes. Colours come only from
  `frontend/src/styles/tokens.css` (accent `#2962ff`, up `#089981`, down `#f23645`). Dark theme is the default.
- **Typography:** the system UI font (Segoe UI on Windows). Dense scale: 13 px for primary controls and table rows,
  12 px for meta (column heads, section labels, kbd, helper text); nothing below 12 px. Numbers use `tabular-nums`.
  Weights 400 / 500 / 600 only.
- **Depth:** 1 px border first. Dark-mode overlays get a soft shadow plus a 1 px top highlight
  (`--shadow-overlay`), never a heavy black glow.

## Banned anti-aesthetics

- Glassmorphism, gradients on controls, glow stacks, neon accents.
- Decorative or ambient motion (loops, bounces, parallax). Loaders are the only looping animation.
- Cartoon illustrations, emoji as icons, decorative pills on static text.
- A second accent hue for interactive elements.
- TradingView branding or assets (the Lightweight Charts attribution logo stays on).

## Accessibility target

- **Level:** WCAG 2.1 AA.
- **Contrast:** text ≥ 4.5:1 on its surface; muted text only for meta.
- **Touch / focus:** mouse-first. Minimum hit target 28 px, most buttons 32 px. Every control is keyboard reachable
  with a visible 2 px `--color-focus` ring; overlays trap focus, close on Esc and restore focus.

## Motion

- Durations: `--duration-fast` 120 ms (hover, colour), `--duration-base` 200 ms (enter, slide), `--duration-slow`
  300 ms (emphasis fades). Exit is shorter than enter and uses ease-in.
- Animate only `transform` and `opacity` (colour fades for state are fine). Motion answers a user action or a price
  change; nothing moves on its own.
- `prefers-reduced-motion: reduce` sets every duration to 0.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal.
- **Capitalization:** Sentence case for UI copy and buttons. The UI is English only.
- **Notes:** tooltips and buttons start with a verb ("Add indicator", "Edit settings"). Missing values show `—`.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react`
- **Notes:** 16–20 px, stroke 1.5–2. No other icon set.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: layout / chrome → `viewports`; overlays → `surfaces`; loaders → `loaders`; motion →
   `motion`. Before finishing UI, run `ux-audit` at 1280 and 960.
3. Use only Lucide icons. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions: removing a single chart object is instant with an Undo toast; bulk or irreversible actions
   (remove all drawings, delete a layout) use a confirmation dialog that names the object.
