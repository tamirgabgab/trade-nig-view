# Tillson T3 (t3)

## Formula
$$ T3 = c_1 e_6 + c_2 e_5 + c_3 e_4 + c_4 e_3 $$ with $e_k$ six cascaded $\mathrm{EMA}_n$ and $c_1 = -v^3$, $c_2 = 3v^2 + 3v^3$, $c_3 = -6v^2 - 3v - 3v^3$, $c_4 = 1 + 3v + v^3 + 3v^2$.

## Defaults
| Param | Default | Why |
|---|---|---|
| Length | 5 | TA-Lib default |
| Volume factor | 0.7 | Tillson's default |
| Source | close | TradingView default |
| Offset | 0 | Display shift |

## Warm-up
First valid bar index: $6(n - 1)$.

## What it measures
A very smooth average with less lag than a plain EMA cascade.

## Differences vs TradingView
Verified exactly against TA-Lib `T3`.

## Pitfalls
- Ramp lag is $3(1-v)(n-1)/2$; $v = 0$ is triple EMA lag, $v = 1$ overshoots.
