# ADR 0016 — Chart tools: compare, patterns, icons, eraser, zoom box, forecast pointer

- Status: Accepted (2026-11-26)

## Context
Round U3 turned the toolbar's "coming soon" buttons into tools and added forecast conveniences. The user chose: XABCD,
ABCD and head and shoulders patterns; compare as % lines on the same chart (up to three); a zoom box in time and
price.

## Decision
- **Compare.** `chartStore.compare` (≤ 3 symbols, saved with the chart and in layouts; the backend resolves them to
  canonical universe symbols, unique, not the chart's own). Adding one switches the scale to %, so the lines start
  together at the left edge like TradingView. Each line is a `LineSeries` fed only at the chart's own bar times
  (`compareLine`): it never adds bars to the time axis (bar indexes stay the main series') and never runs past a
  replay's cursor. The legend shows the close at the hovered bar, never a later one.
- **Patterns** are drawings (`xabcd` 5 points, `abcd` 4, `head_shoulders` 7) drawn by click-click like the other
  multi-point tools. Their ratios are of price moves of legs (`patterns.ts`: AB/XA, BC/AB, CD/BC, AD/XA; BC/AB,
  CD/BC), labelled on dashed lines; the neckline runs through the two neck points to the last one.
- **Icons**: an `icon` drawing (one point, `icon` + `icon_size` props, validated by the backend). The path data of 14
  Lucide icons was extracted into `drawings/iconPaths.ts` (ISC) and stroked with `Path2D`: no new dependency.
- **Eraser and Zoom in** are pointer tools in the drawing store (`pointerTool`), not drawings. The eraser removes
  the drawing under a click (with Undo) and stays on; the zoom box (a dashed rectangle) calls
  `ChartEngine.zoomTo`, which sets the logical range and the price scale's visible range (auto-fit off).
- **Go to date** reuses the replay's `DatePicker` (icon-only) and `chartDataStore.focusBar`.
- **Forecast pointer.** `ChartEngine.onPointer`/`onClick` report the logical index and price also past the last
  bar; hovering a forecast candle shows its median and 50/80/95 % ranges, a click inside its 95 % band opens the
  Forecast tab (`uiStore.openSidebar`).

## Consequences
- + Every former placeholder in the toolbars works; alerts and the calendar stay for a later phase.
- − Compare lines use the library's % mode: relative to each line's first visible value, as TradingView does.
- − The extracted icon paths must be regenerated by hand if the icon set grows.
